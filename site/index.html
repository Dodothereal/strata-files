Disk usage

See where your space went.

Switch any folder to Disk Usage and see it as a map, sized by what's inside. Then use Large Files and Duplicates in the sidebar to reclaim gigabytes in minutes.

Views

Four views. Two panes.

Icons, List, Columns and Disk Usage, one keystroke apart, just like Finder. Turn on Dual Pane to work with two folders side by side and copy or move between them with a keystroke.

For developers

It knows your projects.

Every file shows its git status, and the current branch sits in the path bar. The inspector recognizes Node, Rust, Swift, .NET, Python, Go and more, lists a project's scripts, and frees the space taken by build folders like node_modules in a click. They go to the Trash, so nothing is lost.

Privacy

Private by design.

Strata runs entirely on your Mac. There's no account to create, nothing to sign in to, and nothing phoning home.

On your Mac, only

Search, summaries and AI features run locally. No accounts, no tracking, no cloud. Your files and your searches never leave the machine.

Encrypted at rest

Strata's file index, content index and history are encrypted on disk, with a key kept in your keychain.

Safe with code you didn't write

A folder can't run its own code just because you looked at it. Strata switches off the git features a downloaded repository could use to do that.

FAQ

Questions, answered.

What do I need to run Strata?

A Mac with Apple silicon running macOS 26 Tahoe. Apple Intelligence is optional: without it, summaries fall back to a document's key sentences and Ask Strata to its built-in rules.

Does it replace Finder?

It works alongside Finder, so you can try it without giving anything up. If you like it, turn on Open “Reveal in Finder” in Strata in Settings, and apps that show files in Finder open Strata instead.

Why does it ask for Full Disk Access?

So it can search and measure everything without macOS asking you folder by folder. It's optional, and Strata walks you through it on first launch. Without it, Strata still works with the folders you open.

Is it safe to download?

Every release is signed with a Developer ID and notarized by Apple, so macOS opens it without warnings. The source is public, and each release lists SHA-256 checksums.

Does Strata collect any data?

No. There are no accounts, no analytics and no servers. The search index and history stay on your Mac, encrypted.

How do I update?

Download the latest version from this page or from GitHub Releases and replace the app in your Applications folder. Strata doesn't check for updates on its own, because it doesn't connect to anything.
