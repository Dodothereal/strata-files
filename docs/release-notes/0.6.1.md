Strata 0.6.1 fixes unnecessary index writes and missing translations, and updates the app icon.

## New
- **A new layered app icon.** Strata uses the Liquid Glass artwork contributed by
  [RemoPro](https://github.com/cristipufu/strata-files/issues/12), with default, dark and tinted appearances.

## Fixed
- **The index avoids unnecessary saves and refreshes.** Strata no longer indexes its own private state or rewrites
  the full index when folder events or settings leave its contents unchanged. This prevents its own saves from
  triggering further work and reduces background disk writes and CPU use. Changes to your files still update the index.
- **View Options and additional list columns are translated in every supported language.** Missing translations
  for the new controls, media details and command-line installation messages are filled in across all 20 translated
  languages, including the German labels supplied in issue #11. Local tests, pull requests and releases now check for
  missing strings, blank translations and incomplete plural forms before a build can be published.
