Strata 0.6.4 fixes view controls during search and Settings in full screen, and adds native color themes.

## New

- **Give Strata your colors.** Settings ▸ Appearance now offers Graphite, Blue, Green, Purple, Sand, Teal, Rose
  and Amber, each with a light and dark palette. Colors carry through the file views, sidebar, inspector, toolbar,
  Settings and other windows while keeping native macOS controls. Choose System for the Mac’s own colors, or turn
  Window tint off to keep native backgrounds with colored selections and accents.

## Fixed

- **View controls reflect the results you’re looking at.** Search, Recents and Duplicates show List as active and
  disable unsupported view choices. Clicking a view button no longer silently changes your folder-view preference
  while results are showing. The controls return when you go back to a folder.
- **Open Settings in the current full-screen Space.** Settings joins the browser instead of taking you back to
  another desktop.
- **Keep Trash last in the folder tree.** Trash follows servers and Containers, matching the sidebar’s other mode.
