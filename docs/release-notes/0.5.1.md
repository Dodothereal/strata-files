Strata 0.5.1 fixes renaming in List view.

## Fixed
- **Renaming in List view keeps the new name.** Typing a new name and pressing Return put the old name back, and the
  file wasn't renamed. The new name now sticks, as it already did in Icons, Columns and Gallery.
- **A rename isn't cut short.** Changes in the folder, or switching to another app and back, could end the edit
  while you were still typing and keep the name as it was so far. The edit now stays open until you press Return or
  Escape, and the folder catches up right after.
