Strata 0.4.0 reaches your servers and remembers your setups.

## New
- **Servers.** Go ▸ Connect to Server (⌥⌘K) now opens SFTP servers and S3 buckets as well as network shares, and
  keeps them under **Servers** in the sidebar (green while connected). Their folders work like any folder: every view,
  Quick Look, previews, copying and dragging things out. Drop or paste files onto a server folder to copy them there
  (with progress in Transfers), make folders, rename and delete (a server has no Trash, so Strata asks first), and
  move things around within a server without downloading them.
  - **SFTP** goes through your Mac's own ssh: hosts, keys, the agent and ProxyJump from `~/.ssh/config` all work, and
    your config's hosts are suggested as you type. A password, or a server Strata hasn't seen before, is asked about
    in a dialog; nothing is stored, and nothing is forwarded to the server. Open in Terminal opens a shell there.
  - **S3**: Amazon S3 and S3-compatible services (Cloudflare R2, Backblaze B2, Wasabi, MinIO…), with the secret key
    kept in your keychain.
  - Files are read as you browse and cleared from your Mac when Strata quits; downloaded ones are quarantined, so
    Gatekeeper checks them before they run.
- **Workspaces, in the sidebar and ⌘K.** A Workspaces section opens a saved setup (or brings its window forward);
  right-click to rename or delete it, or, in its own window, to update it with the tabs you have now. Save Workspace
  shows the tabs with their folders and views, and says when a name would replace another. Each pane's view comes
  back, and so do folders on network shares and servers: opening the workspace connects to them again. Folders that
  are gone are listed, with Remove from Workspace; folders on a disk that isn't plugged in are kept. `strata -w <name>`
  opens one from the terminal.
- **Folder tree.** A switch beside Hide Sidebar shows the sidebar as a tree of folders: Home, each disk, the Trash,
  your servers and containers. It follows the folder you're in, takes drops, and springs folders open while dragging.
- **The path bar suggests folders** as you type: inside the path typed, `github/acme`-style lookups, or a name alone
  for folders with that name anywhere. ↑ ↓ to choose, Return to go, Tab to complete.
- **⌘+ and ⌘−** change the text size in List and Columns (they still change icon size in Icons).

## Fixed
- **Quitting no longer waits for the index to catch up.** After a burst of file changes, quitting could take minutes;
  now the index stops within a couple of seconds, and the next launch picks up where it left off.
