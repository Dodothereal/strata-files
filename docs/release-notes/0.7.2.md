Strata 0.7.2 adds six new color themes, a website in all 22 supported languages, and six translated READMEs. It also makes the website easier to read in light or dark mode and faster to load.

## New

- **Six new color themes.** Slate, Sage, Coral, Plum, Ice and Midnight join the existing eight palettes in Settings ▸ Appearance ▸ Color theme. Each works in light and dark mode, with coordinated colors across file views, the sidebar, inspector and window chrome. System keeps your Mac’s own colors.
- **Contribute a palette with a theme file.** Themes are now defined in JSON files and discovered automatically when Strata is built. Contributors can add a palette and its translated name without changing Swift code. Native controls, accessibility fallbacks and contrast checks stay shared across all themes.
- **Read the website in your language.** All 22 app languages now have translated pages and a native-language picker. Your browser’s language settings can suggest a translation; an explicit language choice stays yours.
- **Light, Dark or System on the website.** The site follows your system appearance by default. Choose Light or Dark to keep an override across pages and visits, or return to System to follow changes automatically.
- **Six translated READMEs.** Russian, Ukrainian, Japanese, Korean, Simplified Chinese and Traditional Chinese guides are linked from the top of the README. They share the English source, screenshots and commands, with checks that catch missing translations and outdated generated files.

## Fixed

- **Website screenshots load faster.** Responsive WebP images keep the native app’s colors, borders and shadows while reducing download size. The Color Themes section now shows the actual Appearance settings window with all fourteen themes and System.
- **Developer features are easier to scan.** The website and README separate repositories, servers and containers into clear sections. The website also has flatter download buttons and a header fixed to the top of the page.
