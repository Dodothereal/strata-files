Strata 0.5.2 adds New File and keeps hidden sidebar sections hidden.

## New
- **New File.** File ▸ New File (⌥⌘N), also in the right-click menu and ⌘K, makes an empty “untitled.txt” in the
  folder you're in and starts renaming it. Settings ▸ General ▸ New Files sets the extension, or none. It works on
  SFTP servers and buckets too.

## Fixed
- **Hidden sidebar sections stay hidden.** A section you hid with Hide on its title came back as soon as you switched
  to another app or window and back. Hidden sections now stay hidden in every window, and after Strata restarts,
  until you show them again.
