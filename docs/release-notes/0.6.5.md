Strata 0.6.5 fixes crashes and improves resilience when previewing files, searching deeply nested folders and loading saved data.

## Fixed

- **Preview demanding files more safely.** Large or deeply nested JSON, unusual archives and oversized database values now respect preview limits. When a limit is reached, Strata keeps the original text, shows a partial preview or explains why reading stopped.
- **Search deeply nested folders without crashing.** Searches that match hundreds of folder levels now handle long paths safely.
- **Recover safely from invalid saved indexes.** Strata rebuilds an invalid file index and skips malformed content-search records while keeping valid records searchable.
- **Keep valid History entries available.** Malformed entries are skipped without hiding valid operations or rewriting the saved History during loading. Incomplete move records cannot reach Undo.
- **Handle unusual layout and Dock geometry safely.** Icons view and Dock integration validate unexpected dimensions and coordinates before using them.
- **Handle failed process-output reads without crashing.** Git reports an output-read failure instead of treating partial output as success, and server diagnostic reads end safely.
- **Avoid blocking on nonregular preview files.** Text previews and app metadata inspect the opened file and limit how much they read.
