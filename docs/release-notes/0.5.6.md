Strata 0.5.6 makes Undo, the Trash, containers' files and servers safer.

## Fixed
- **The Trash itself can't be moved to the Trash or deleted.** With hidden files shown, the Trash can be selected in
  your home folder like any item, and Move to Trash and Delete Immediately then acted on it, with everything in it.
  Both now refuse, also when the Trash is reached through a link.
- **Undo touches only the items it undoes.** Undoing a copy, Duplicate, New Folder or New File moved whatever had that
  name to the Trash, even a different file saved there since; undoing a move or rename moved back whatever was at that
  place. Undo and redo now act only on the very items the operation left, and leave anything that took their place.
- **Undo and redo pressed quickly happen in order.** An undo whose moves took a moment (across disks, or behind other
  work) could be overtaken by the next press, which then found nothing to do and skipped a step. Every step now waits
  for the one before it.
- **Undoing an Ask Strata plan is checked the same way.** Undo and redo of a plan moved or trashed whatever was at
  those paths by then. They now take only the plan's own items, and redo makes only the folders those steps need.
- **A file opened from a container holds only that file.** When the container sent more than the one file, the extra
  data was added to it.
- **Copying onto a server never replaces anything unasked.** Copying items onto a server where some names are already
  taken asks first. If the window had closed while the names were being read, everything was replaced instead; those
  items now stay as they are and the rest is copied.
- **Installing the `strata` command replaces only Strata's own link.** It could remove an unrelated `strata` in
  `/usr/local/bin`.
- **A new name can't move an item.** A name typed with a slash in it moved the item into another folder; such a name
  is refused.
- **Remove Download frees only the items chosen.** Never through a link, which would free what it points to, and each
  item once.
