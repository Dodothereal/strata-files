Strata 0.4.3 groups Compose projects into stacks and fixes aliases, Icons view clicks and Settings.

## New
- **Compose stacks.** In Containers, a Compose project's containers come together in a folder of their own, a stack.
  Select one to see in the Inspector how many of its containers run, start, stop, restart, pause or resume them all at
  once, and open the project folder in your terminal or in a code editor installed on this Mac (Visual Studio Code,
  Xcode, Zed, JetBrains IDEs and others). The same Open in Terminal and Open With are in the stack's context menu.
- **New container icons.** A container is a box and a stack is a stack of boxes: filled green while running, a grey
  outline when stopped, orange while paused or changing.
- **Date Created.** Sort by Date Created from View ▸ Sort By (⌃⌥⌘6), and show it as a column in List view:
  right-click the column titles to show or hide Date Modified, Date Created, Size and Kind. The list also remembers how
  you last sorted it.
- **A lighter Inspector.** Sections are divided by thin lines instead of sitting in rounded cards, leaving more room
  for their contents.
- **Icons for every menu command.** Strata's own commands in the menu bar have icons like the standard ones, instead of
  sitting indented without one.

## Fixed
- **Aliases and links to folders open in Strata.** Double-clicking a Finder alias to a folder opens that folder here
  instead of in Finder, and links to folders open however you reach them (a restored window, a workspace, spring
  loading).
- **A click selects in Icons view.** Clicking an icon selected nothing until you dragged; it selects now.
- **Settings stays a comfortable size.** Each tab is as tall as it needs to be, up to a fixed height (less on a small
  screen); a longer one scrolls instead of running off the screen.
- **Expanding an Inspector section** no longer upsets its layout.
