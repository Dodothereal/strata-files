Strata 0.7.0 fixes interrupted renames, improves file operations and navigation across windows and servers, and adds a custom startup folder and Russian localization.

## New

- **Choose where new windows open.** Settings ▸ General ▸ New windows open now includes Custom folder with a native folder picker. Strata remembers your choice and falls back to your home folder if the selected folder is unavailable. Restored windows keep their saved locations.
- **Use Strata in Russian.** Russian joins the supported languages, with translations contributed by [Da1m0s](https://github.com/Da1m0s).

## Fixed

- **Rename without interruptions.** Folder-size, index and media updates no longer cancel a List rename or commit a partially typed name. Escape and unchanged-name edits refresh any deferred details. In Columns, the old name stays hidden behind the rename field until editing ends.
- **Move up reliably in Columns.** ⌘↑ moves focus to the parent column and selects the folder you came from. Repeated presses continue upward, and a delayed folder-open result cannot send you back into the child folder.
- **Keep selections and new-item renaming in place.** Refreshes preserve choices made while a folder loads. New File, New Folder and completed operations wait for their items to appear before selecting or renaming them, including in deeper Columns. Late folder and search results cannot replace a newer location.
- **Keep navigation with the right pane.** Slow server or container openings finish in the pane that requested them. Navigation, closing or Cancel prevents stale results from taking over. Saved workspaces retain their correct tabs, pane layouts and locations.
- **Undo and retry the right files.** Undo leaves replacement files and folders alone. Retried transfers repair only the incomplete copies they created, keep History in sync, and preserve the originals until a complete replacement is ready. File creation, renaming, project cleanup and Ask Strata changes stay with the correct Undo history.
- **Connect and reconnect more reliably.** SMB and WebDAV connections accept ordinary share addresses reliably. Cancelling one connection does not disconnect another pane, old failures cannot retire a newer session, and failed credential updates preserve the saved password.
- **Keep failed SFTP replacements recoverable.** On servers without atomic replacement, uploads keep the original until the completed upload can take its place. If replacement and rollback both fail, Strata preserves both copies and reports their recovery paths.
- **Show consistent details for server and container files.** Listings, thumbnails, previews, media details and folder sizes use the correct file provider. Fetching missing contents refreshes those details; Stop and navigation reject late updates. Late preview results no longer update a closed pane or window.
- **Handle demanding files and metadata more carefully.** Additional limits cover binary property lists in previews, tags, Finder comments and app metadata, as well as Markdown images, SQLite tables and folder scans. Markdown preview images are confined to the document’s folder and its subfolders. Directory-name decoding, index growth and malformed saved data have stronger validation.
- **Protect files when browsing untrusted content.** Background Git checks disable configured filter commands; repositories that rely on clean filters may show different status badges than command-line Git. Archive extraction adds stronger checks for links, permissions and hidden top-level items. Copied container links are checked before a transfer finishes, and deletion and metadata edits verify that the chosen item has not been replaced.
- **Keep folder trees and commands responsive.** Collapsed and closed folder trees release their file watchers so later folders keep updating. Menus and the command palette agree on which actions are available for the current view, selection and pane.
