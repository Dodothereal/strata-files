Strata 0.3.3 fixes dragging files to other apps, and a crash.

## Fixed
- **Dragging keeps working.** Dragging files out of Strata (into a browser, Mail or any other app) worked once,
  then pressing and dragging only changed the selection until you restarted Strata. Every drag works now, from the
  list, columns and the sidebar.
- **A crash with the Inspector in a narrow window.** Strata could crash when the hidden Inspector slid into view in a
  narrow window. The sidebar, the files and the Inspector now always fit the window's smallest size, so showing the
  Inspector or searching no longer widens the window by itself.
- **Long folder names in dual pane** shorten in the pane's header instead of making the window wider.
- **Dual pane layout warnings**: hiding a pane's header or status line no longer briefly fights the layout.
