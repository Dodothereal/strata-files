Strata 0.2.1 tidies up the Inspector. If you have 0.2.0, this is the first update that installs itself.

## Changed
- **Project, Git, Build Artifacts and Scripts are cards** in the Inspector, like Information, Tags and Comments: each
  has its own header and collapses with its chevron, and Strata remembers which ones you closed. The Git card shows the
  upstream branch in its header, Build Artifacts their total size, and Scripts the runner.
- **Update notes show right in the update window**, instead of a web page.
