Strata 0.3.2 finishes the scrolling fix from 0.3.1.

## Fixed
- **Back opens folders at the top too.** Going Back (or Up) from a long folder you had scrolled down showed the
  folder you returned to partway down, its few items floating in the middle. A folder you open now always starts
  from its top, then scrolls to the folder you came from if it's further down.
