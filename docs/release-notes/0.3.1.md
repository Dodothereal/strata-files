Strata 0.3.1 fixes two things in 0.3.0's containers.

## Fixed
- **Folders open at the top.** Opening a folder sometimes showed it where the previous folder was scrolled, stuck
  partway down or sliding in from below, most often in a container, whose listing arrives while the folder opens.
  A folder you open now always starts at its top, in the list and in icons.
- **Programs in a container look like programs.** A file not read from the container yet showed as a plain
  "Document"; it now shows as a Unix Executable File, with the same icon and kind as anywhere else on your Mac.
