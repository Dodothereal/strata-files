Strata 0.3.0 opens up your containers.

## New
- **Containers.** With Docker Desktop, OrbStack, Colima, Podman, Rancher Desktop or Lima running, **Containers**
  appears in the sidebar and shows your containers as folders, with a green badge while they run. Open one to browse
  its files from `/`, like any folder: Quick Look, open, search, and copy or drag things out (folders come out whole;
  bigger reads show in Transfers, where you can stop them). Nothing in a container is changed: its files are read as
  you browse, and cleared from your Mac when Strata quits.
- **Start, stop, restart, pause and resume** containers from the context menu, the inspector or the command palette.
  Stopping several at once asks first.
- **Open in Terminal** inside a container opens a shell in it, in the folder you're looking at.
- **The inspector** shows a container's image, state, ports and mounts (click a mount to go there). In a project with
  a Compose file it lists the services, which of them run, and offers Start All and Stop All.
