Strata 0.5.3 fixes deleting folders in Columns view.

## Fixed
- **Deleting a folder in Columns view keeps the folder it was in.** Deleting a folder for good (⌥⌘⌫) from any column
  but the first closed the column it was in, so that folder and everything in it disappeared from view, and the title
  kept the deleted folder's name. The column now stays, showing what's left, and the title follows.
