Strata 0.5.5 makes moving files and Ask Strata safer.

## Fixed
- **Moving two items with the same name keeps both.** Moving or copying two items with the same name from different
  folders (from search results or Duplicates, say) into one folder could send the first one to the Trash if you chose
  Replace. The second one now goes beside it, with a number. Replacing what was already in the folder works as before.
- **Ask Strata moves things only where you asked.** A plan could move items into a folder above the one you named, or
  one whose name only started the same. Outside the window's folder, it now moves items only into a folder your request
  names in full.
