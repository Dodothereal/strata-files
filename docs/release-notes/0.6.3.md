Strata 0.6.3 fixes memory spikes, horizontal scrolling in Columns, and leftover dividers and Dock space.

## New

- **Read Strata’s app privacy policy.** The website now explains how the app handles your files and data, with a
  link from the README.

## Fixed

- **Content search uses less memory.** The default content-search index no longer allocates storage for sentence
  vectors it does not use. Search results stay the same.
- **Keep thumbnail memory under control.** A bounded cache releases unused images under memory pressure without
  reducing thumbnail quality. Older previews may be generated again when you revisit a folder.
- **Reduce memory spikes when the file index grows.** Loaded indexes reserve room for new entries, avoiding
  unnecessary buffer copies during a burst of file changes.
- **Reject invalid saved indexes without crashing.** Invalid column lengths are checked before allocating memory.
- **Scroll Columns while hovering folder lists.** Sideways gestures work over folder rows and empty column space,
  including deep folder trees. Vertical scrolling stays in the individual folder, and momentum keeps its direction.
- **Remove the leftover divider after closing dual-pane mode.** The second pane’s divider no longer remains in the
  footer in Columns or Disk Usage.
- **Remove the Dock search gap when Strata quits.** Quitting removes Strata’s reserved search space while preserving
  your Dock layout and spacers.
