Strata 0.7.3 makes everyday browsing more convenient with cloud folders in the sidebar, a customizable toolbar, Finder tags in List view, easier search filters and control over which transfer runs next. It also remembers each pane’s Back and Forward history when reopening windows.

## New

- **Cloud account folders in the sidebar.** Strata discovers iCloud Drive and account folders exposed through macOS by sync apps such as Google Drive, OneDrive and Dropbox. Each account stays separate and appears after its sync app has created a local account folder. Cloud-only files show a badge, and Download Now can ask the provider to download an individual file. Folder-wide offline, pinning and sharing controls remain in Finder or the provider’s app.
- **Choose your toolbar buttons.** Open View ▸ Customize Toolbar, or right-click the toolbar, to add New Folder, New File, Move to Trash, Open in Terminal, Quick Look, Reload and Command Palette. Rearrange the controls and choose icons or icons with labels; Strata remembers your choices. The current layout remains the default.
- **Finder tags as a List column.** Enable Tags from the column header menu or View Options to see your own tag names. Click the header to sort, or choose View ▸ Sort By ▸ Tags in the other views. Keep Folders on Top still applies, and background tag updates retain your selection and expanded folders.
- **Back and Forward with your mouse or trackpad.** Mouse side buttons navigate the pane under the pointer. Trackpad page swipes follow macOS’s swipe setting, while horizontal scrolling in Columns and Gallery keeps its usual meaning.
- **Reopen each pane’s browsing history.** With Reopen Windows enabled, Strata restores Back and Forward history, the active pane and the selected tab alongside your folders and views. Local searches, Recents and Duplicates remain part of that history. Named workspaces continue to open with fresh history, and reopening windows does not start a server login.
- **Edit search filters without starting over.** Filters… opens a native popover for kind, extension, size, modification date and download source. Applying a change preserves the other search terms, quoted names and date boundaries. Cancel leaves the search alone.
- **Find files by where they were downloaded from.** Search for `source:github.com`, or type “downloaded from github”. This uses Spotlight’s saved source information, so files need source metadata and must be indexed by Spotlight to appear.
- **Decide which waiting transfer runs next.** Use Run Next on a waiting copy or move, or Move Up and Move Down from its context menu. Queued Compress and Extract jobs have the same controls. Active work keeps running, transfers to separate disks remain independent, and finished jobs keep their usual order.

## Fixed

- **Customize Toolbar aligns with the display options above it.** Its wrench and label now use the same columns as the native menu’s checkmarks and text, including when opened with Control-click.
- **Tag names stay visible while metadata refreshes.** Browsing an enclosing folder in another window no longer temporarily clears already loaded tag names while a fresh read is pending.
