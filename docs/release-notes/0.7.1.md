Strata 0.7.1 fixes duplicated language options in Settings and adds a new Quick Look browser for folders and archives, offline HTML previews and a preview window that remembers its layout.

## New

- **Look inside folders and archives with Space.** Browse nested contents and preview a selected file alongside the list, while keeping your main browser in place. Archive listings open without unpacking the whole archive.
- **Choose a list or thumbnails.** Filter names, sort the contents, browse photos as icons and adjust thumbnail size. Quick Look keeps its view settings separate from the main browser.
- **Open or copy just what you need.** Open, Copy, Copy Path and Show in Strata act on the item selected in the preview. Supported archive members can be previewed or copied individually; encrypted ZIP files can ask for a password. Items that require full extraction explain why.
- **Read HTML with its formatting.** HTML files have a rendered local preview and a source view in Quick Look and the inspector. Local styles and images are supported; JavaScript and network loads stay disabled.
- **Browse servers and containers without downloading whole folders.** Quick Look lists their contents first and fetches individual files as needed for previews. Copying a folder remains an explicit action.
- **See file size and space on disk.** Quick Look distinguishes a file’s logical size from its allocated disk space. Calculate Size measures a local folder when requested, with Cancel available while it works.
- **Keep a comfortable preview layout.** Quick Look remembers its window size, pane proportions and manually resized metadata columns. The file list adapts as the window narrows, and previews follow your existing light, dark and color-theme settings.

## Fixed

- **Each language appears once in Settings.** The language picker no longer lists every translation twice. Regional and script variants remain separate choices.
