Strata 0.2.4 keeps the Inspector steady while your files change.

## Fixed
- **The Inspector no longer flickers** while files change in the background, from downloads, builds or an editor
  saving. Strata used to rebuild the Inspector's details, switches and menus several times a second even when
  nothing in them had changed; now it only updates what actually changed. A git change refreshes just the Git card.
- **Disk Usage stays still and uses less CPU.** The map no longer replays its animation on every change on your Mac,
  only when sizes in it really move.
