Strata 0.6.0 adds View Options, more list columns and built-in apps in Applications.

## New
- **Choose what appears under icons.** Open View ▸ Show View Options… (⌘J) to show or hide item info and choose item
  counts or total sizes for folders. Pictures and movies show their dimensions. Icon size, previews and list columns
  can be adjusted here too; these choices apply to every window.
- **See more details in the list.** Optional Dimensions, Width, Height, Duration, Date Added and Extension columns
  join the existing columns. Choose them in View Options or by right-clicking the column titles. Media details load
  in the background, account for rotation and sort numerically.
- **Applications includes built-in apps.** Apps from `/System/Applications` appear alongside those in `/Applications`.
  Entries keep their real locations, including separate apps or Utilities folders with the same name.

## Fixed
- **Go menu icons stay visible on macOS 27.** Folder destinations and other commands explicitly keep their icons
  when the system would otherwise hide them.
- **Folders, apps and bundles show their localized names.** Views, previews, the path bar and search results use
  the names macOS provides. Filtering accepts both the visible name and the name on disk; renaming keeps the original
  name available, and file commands act on the selected item’s real location.
- **Extra list columns remain reachable in narrow panes.** A horizontal scroll control appears when the columns
  need more room, including in Dual Pane.
